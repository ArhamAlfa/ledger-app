Connect the ledger

This dashboard keeps nothing of its own. It reads and writes log.csv and config.json in a private GitHub repo. Paste a fine-grained token with Contents: read & write on that repo. It is stored only in this browser, and you do this once per device.

Accounts & tags

Tags describe what a purchase was. They do not hold their own money — the account does. A tag belongs to an account only so it knows which currency to use.

Rhythm

The daily rate is this account's balance divided by the days left before the reset.

Start a budget

Any length you like. Amount is the variable money the daily number is built from. Overhead is laundry, bills and the like — logged as normal, but never counted against the daily plan.

Amend the current one

Raising the budget is a recorded decision. Topping up is not — it just counts as overdraw.

Close out the month

The current log.csv is copied into months/ and kept forever. A fresh log then opens with the balances below as income rows, so the new month starts with whatever money actually still exists.
